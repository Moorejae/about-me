About

I'm an applied AI engineer: I build agentic systems that run in production, and I build them with AI agents. ForChi runs three workflows around the clock. REZMO serves a user's own memory to Claude and Grok over MCP. Both were designed, written and deployed in a loop with coding agents, with me holding the architecture and the judgement.

That distinction is the job now. Anyone can prompt a model. Knowing what to build, directing agents until it is correct, and then owning what ships to real users — that is the work I do.

The infrastructure underneath is mine too: Cloudflare, AWS, Google Cloud (including Vertex AI), Oracle Cloud and Contabo, with the security designed in rather than bolted on.
