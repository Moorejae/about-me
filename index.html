About

I build and run cloud systems end to end, with hands-on work across AWS, Azure, Oracle Cloud and Google Cloud: IAM, networking, storage buckets and tenancy setup.

I also build AI systems that run in production — agents, RAG and multi-step automation — including a Telegram agent that runs three workflows around the clock. Security is designed in from the start: encrypted services, separate hosts for data and keys, hardened ports.

I also design, build and deploy websites for small businesses and NGOs, and run the hosting for them: Cloudflare (Workers, Pages, DNS, WAF), Netlify and Hugging Face, alongside AWS, Google Cloud and Oracle Cloud where the workload needs it.
