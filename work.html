REZMO: Portable AI Memory Layer

A user's conversations and files live in their own Google Drive, and any connected model picks up the same context. Claude and Grok both connect through an MCP server I built.

The API, Postgres 17 and Redis run as containers on one Contabo host behind Cloudflare, with the frontend on a Cloudflare Worker. Moving the database next to the API cut the round trip from about 112 ms to about 5 ms.

Covered by 2,000+ backend tests and 480+ frontend tests, with live payments shipped through Paystack.

ForChi: Telegram Automation Agent

Three workflows in parallel: social posts to Facebook and LinkedIn five times a day (copy written through Vertex AI, images generated on a Hugging Face model), a YouTube video pipeline of up to two videos a day, and a job-application workflow that scans every 30 minutes, scores roles with Gemini and applies through Lever and Ashby.

A deterministic trigger layer (regex gate, then a Zod-schema extractor) keeps casual chat from ever firing a workflow. The LLM stack is Gemini with a Qwen2.5-7B model I host on Hugging Face as fallback.

It runs on free tiers (Render, Hugging Face) and cut the manual time I spent on these tasks by about 99.9%.

WCM: Live Pricing Model

WCM is a live pricing model for football.com: closing-line priors, a probability shrunk toward the market, and a checkpoint dataset that logs every bet it skips so the model can be calibrated instead of argued about.

Built from a written specification, with 145 tests asserting every worked example and every behaviour the live API actually has, including the regression that came out of the night it lost a full allocation by letting the scanner pick a side the formula disagreed with.

The predecessor was the V6.1 football engine, which scored fixtures from raw kinetic and tactical data with three weighted pillars, versioned framework patches and a diagnostic autopsy on every settled result.

CloudVoid: Archived Build

A non-custodial multi-chain wallet covering 15 chains, now decommissioned. It stays in this portfolio as an archived build: it is where I worked out key custody, encrypted transport and runtime hardening.

Private keys never left the device, and the backend only saw public addresses through an encrypted envelope (P-256 ECDH, HKDF-SHA256, AES-256-GCM) with the master key held on a separate server.

The operational patterns from that build, PM2 monitoring, iptables hardening, automated return-to-source, now protect the systems I run today.

Crypto Bank Platform: OCI

A containerised banking front end deployed on Oracle Cloud's Always Free tier. In production the heavy Node runtime is dropped for a static NGINX delivery layer, cutting live memory to under 5 MB. The image is multi-stage, so node_modules and build scripts never reach the running node, and the backend steps down from root to the node user. Kubernetes manifests live alongside the app.

LinkedIn AI Agent: Resilience Layer

The publishing agent behind the social workflow: a key-rotation engine pools API credentials and rotates on quota or invalid-key errors instead of crashing, while a dual-axis fallback cascades between models when a provider degrades.
