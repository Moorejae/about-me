REZMO — Portable AI Memory Layer

A user's conversations and files live in their own Google Drive, and any connected model picks up the same context. Claude and Grok both connect through an MCP server I built.

The API, Postgres 17 and Redis run as containers on one Contabo host behind Cloudflare, with the frontend on a Cloudflare Worker. Moving the database next to the API cut the round trip from about 112 ms to about 5 ms.

Covered by 2,000+ backend tests and 480+ frontend tests, with live payments shipped through Paystack.

ForChi — Telegram Automation Agent

Three workflows in parallel: social posts to Facebook and LinkedIn five times a day, a YouTube video pipeline of up to two videos a day, and a job-application workflow that scans every 30 minutes, scores roles with Gemini and applies through Lever and Ashby.

A deterministic trigger layer (regex gate, then a Zod-schema extractor) keeps casual chat from ever firing a workflow. The LLM stack is Gemini with a Qwen2.5-7B model I host on Hugging Face as fallback.

It runs on free tiers (Render, Hugging Face) and cut the manual time I spent on these tasks by about 99.9%.

Honk — V6.1 Football Engine

Honk is a sports prediction system that reports a 70–80% success rate. The engine underneath it is bookmaker-independent: it never reads odds, lines or market movement, scoring fixtures instead from raw kinetic and tactical match data.

Three structural pillars — kinetic velocity, defensive elasticity and structural integrity — feed a set of hard-coded framework patches, guarded by a market-decoupling veto and a virtual-fixture kill switch.

On finished fixtures it runs a Diagnostic Recurrence Analysis to autopsy why a prediction hit or missed, so the framework tunes from evidence rather than opinion.

CloudVoid — Archived Build

A non-custodial multi-chain wallet covering 15 chains, now decommissioned. It stays in this portfolio as an archived build: it is where I worked out key custody, encrypted transport and runtime hardening.

Private keys never left the device, and the backend only saw public addresses through an encrypted envelope (P-256 ECDH, HKDF-SHA256, AES-256-GCM) with the master key held on a separate server.

The operational patterns from that build — PM2 monitoring, iptables hardening, automated return-to-source — now protect the systems I run today.
