Strategy

Approach

The Engineering Mindset

I operate with a data-first approach, treating infrastructure and automation as production-grade software. Reliability, observability, and security are not features—they are the foundation of every deployment.

Mission

1 - Build It, Then Run It

I do not hand over a diagram. REZMO, ForChi and Honk are systems I operate in production across Cloudflare, Contabo, Oracle Cloud, Render and Hugging Face, shipped through GitHub Actions.

2 - Remove the Human Loop

Deterministic triggers in front of probabilistic models: a regex gate and a schema extractor decide whether a workflow fires, so the model does judgement calls, not traffic control.

3 - Assume the Breach

Keys and data live on separate hosts, ports are hardened, and runtimes are monitored. If code changes unexpectedly, the system restores clean files from GitHub instead of trusting the box.
